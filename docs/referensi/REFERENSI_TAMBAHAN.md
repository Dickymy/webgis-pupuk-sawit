## TIPS MENAMBAH KE MENDELEY

1. **Dari DOI:** Di Mendeley Desktop, klik File → Add Entry Manually → masukkan DOI → metadata otomatis terisi
2. **Dari PDF:** Drag PDF ke Mendeley → metadata biasanya ter-extract otomatis
3. **Buku (Pahan):** Add Entry Manually → Type: Book → isi judul, penulis, tahun, penerbit, ISBN
4. **Setelah selesai:** Export ulang dan taruh di `docs/referensi/My Collection.bib`
