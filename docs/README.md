- `KETERBATASAN_SISTEM.md`: batas klaim dan penggunaan hasil.

Catatan audit, migrasi, dan revisi versi lama sengaja tidak disimpan sebagai dokumentasi aktif. Riwayat perubahan tersedia melalui Git.
